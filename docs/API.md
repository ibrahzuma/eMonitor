# API reference (overview)

The complete, always-current specification is generated by FastAPI:

* OpenAPI JSON: `GET /api/v1/openapi.json`
* Swagger UI: `/api/v1/docs` · ReDoc: `/api/v1/redoc`

## Conventions
* Base path `/api/v1`, JSON bodies, UTC ISO-8601 timestamps.
* **Auth**: `Authorization: Bearer <access JWT>` (users) or `Authorization: Bearer emk_...` / `X-API-Key: emk_...`
  (API keys). Agents use `Authorization: Agent <agent_id>.<secret>`.
* **Tenant**: `X-Organization-ID: <uuid>` selects the organization (optional when the user has one membership;
  fixed for API keys).
* **Pagination**: `?page=1&page_size=50` → `{"items": [...], "total", "page", "page_size"}`. Logs use cursors:
  `{"items", "next_cursor"}` → `?cursor=...`.
* **Errors**: `{"error": {"code", "message", "details", "request_id"}}` with HTTP 400/401/403/404/409/422/429/503.
  422 `details` is a list of `{loc, msg}`. 429/503 include `Retry-After`.
* **Correlation**: send `X-Request-ID` (≤64 chars `[A-Za-z0-9._-]`) or one is generated; it is echoed and logged.
* Time ranges: `?range=15m|1h|6h|24h|7d|30d|90d` or `?start=...&end=...`.

## WebSocket `/api/v1/ws`
1. Connect, then send `{"type":"auth","token":"<access token>","organization_id":"<uuid>"}` within 10 s
   (tokens are never put in the URL).
2. Server replies `{"type":"ready"}` and pushes `{"type","ts","data"}` events: `incident`, `resource_status`,
   `check_state`, `metrics`, `notification`, `logs`.
3. `{"type":"subscribe_logs","q","severity","application","host"}` streams `{"type":"log_tail","data":[...]}`;
   `unsubscribe_logs` stops it; `ping` → `pong`. If live events are unavailable the server sends
   `{"type":"error"}` and closes with 1011 (clients fall back to polling).

## Examples
```bash
# Log ingestion from an application (API key with logs:write scope)
curl -X POST https://monitor.example.com/api/v1/logs/ingest -H "X-API-Key: $KEY" -H 'Content-Type: application/json' \
  -d '{"records":[{"message":"payment failed","severity":"error","application":"billing","trace_id":"abc123","attributes":{"order":"42"}}]}'

# Custom metrics from an exporter (API key with metrics:write scope)
curl -X POST https://monitor.example.com/api/v1/metrics/ingest -H "X-API-Key: $KEY" -H 'Content-Type: application/json' \
  -d '{"points":[{"resource_id":"<uuid>","metric":"queue_depth","value":17}]}'

# Availability report as CSV
curl -H "Authorization: Bearer $TOKEN" "https://monitor.example.com/api/v1/reports/availability?range=30d&format=csv" -o availability.csv
```
